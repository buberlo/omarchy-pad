# Opt-in nonfatal guest thread sampling

The sampler is a per-launch diagnostic. It captures x86 RIP, RSP, RBP and selected registers from each signaled guest thread, then returns. It does not unwind a stack, allocate, resolve symbols, walk `/proc`, or hold a library mutex inside the handler. The existing fatal reporter remains a separate preload.

Use the served `fex-game-sample-report` wrapper after the existing EGL wrapper, through `LINPAD_EGL_FEX_BINARY=/tmp/fex-game-sample-report`. It requires `/tmp/x86-thread-sample.so`, the existing `/tmp/x86-game-crash-report.so`, and the unchanged patched FEX binary. It preserves arguments and working directory. Wait for `X86_SAMPLE_READY signal=23`, then run `/tmp/thread-sample-send PID all` from the native ARM64 shell. The sender accepts an explicit TID instead of `all`; it never discovers or chooses a game PID. Capture the resulting `X86_SAMPLE` lines and a matching `/proc/PID/maps` snapshot for offline symbolization.

SIGURG23 defaults to ignore in LinPad, is unblocked on all nine captured build4446 game threads, and is absent from their caught dispositions. SIGWINCH28 was rejected because SDLTimer blocks it. Exact installed Mono ELF functions `GC_get_suspend_signal` and `GC_get_thr_restart_signal` return30 and24 by default; `GC_stop_init` installs those handlers. FEX reserves63 for pause. These checks establish the signal choice for this diagnostic run, not a universal application guarantee.

The constructor refuses to reserve SIGURG if an existing handler or explicit ignore owns it. A later public `sigaction`/`signal` replacement invalidates the readiness token before returning the signal to the application. The native sender requires an active private regular token file and matching live PID/starttime before every `tgkill`. LinPad derives starttime when `/proc` is read, with one tick of observed drift; the identity check allows two ticks. Arbitrary direct signal syscalls can bypass interposition, and token checking is not atomic with all application changes. SIGURG's default-ignore action prevents a lost default disposition from terminating the process. Do not send signals to a launch without the ready marker and valid token.

Local validation used the actual served ARM64 sender against an x86 process under the patched FEX binary and current macOS LinPad CLI. It captured three distinct guest instruction pointers: a main thread in sleep, a running loop, and a blocked futex. All resumed; both workers joined; the target exited0. Installing an application handler disarmed the token, preserved the new handler, and made the sender return2 without delivering another signal. See `sample-local-excerpt.txt` and `thread-sample-provenance.json` for full log fingerprints. Physical build4446 PID1729 accepted all nine native tgkill calls but produced zero guest sample records while the FEX metadata fault held the process. It was later manually stopped (wrapper137). This failed physical callback attempt does not invalidate the separate local control, and it does not qualify physical sampling.

The exact Mono library SHA256 is `682d74f03efd9cebd05d38e82c4b296a0a1865f070440281aa1ac51022220b94`. It has no `GC_MARKERS` string, and `GC_start_mark_threads` at0x27858c consists solely of `ret`. `GC_thr_init` reads `GC_NPROCS`, but the seven `AssetGarbageCo` threads should not be labeled Boehm parallel markers. A marker-count environment change is therefore unsupported by this binary audit. The proprietary Mono and Unity binaries remain local and must not be archived.

The archive adds `build.sh` as a reconstruction recipe that writes a separate scratch output directory. This recipe was shell-syntax checked; it has not been used to replace or requalify the recorded served binaries. Their exact hashes remain the provenance anchors. Local execution requires the separate fatal reporter and runtime noted above.
