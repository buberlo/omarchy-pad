# LinPad 1.5.0 build 4445

Build 4445 is built, developer-signed, installed and booted on the physical iPad. Native JIT uses a 512 MiB arena. Memory-protection probes pass, and the patched FEX runtime completes a 1200-frame Vulkan cube run with visible motion. Hollow Knight remains unplayable in the captured game test: Unity reports missing `libGL.so.1` when creating its main window. No steady-state FPS or game performance is qualified.

The PROT_NONE guard prevents kernel copies and diagnostic frame walks from dereferencing inaccessible guest memory. Explicit read/execute permission for the vDSO and read permission for vvar preserve Alpine startup. Build 4444 exposed the legacy zero-permission mappings and was rejected before desktop startup; it remains unchanged as a local diagnostic artifact. Both fixes were committed before the build as `29c99bc46075a048f422fe4b714e7d531be726ee` and `08528edebc03aa4f07f6b49fdae5d8c08cd2bcd0`.

Local Mac CLI validation uses the actual bundled Alpine musl and BusyBox. Sixteen cases pass across inline JIT, compact tier 1, tier 2 and gadget execution: dynamic Alpine startup with shell/fork/exec/clock, protected-memory syscall reads, protected x29 fault frames and lazy protected x29 fault frames. The 24 exact-address fault regression also passes. Earlier static tests and the reproduced Alpine startup failure are preserved with raw-log hashes; those earlier static tests alone did not qualify dynamic startup.

Physical protection results are in `build4445-protection-validation.txt`, with exact script `validate4445`. All three protected-memory invocations and the 24-case null-fault probe pass. `install.json` records successful installation and `device-launch-evidence.txt` freezes native JIT and boot lines. The memory snapshot reports 706 MiB footprint, 8192 MiB allowance, 7485 MiB headroom and zero OOM kills.

The exact `cube4445-patched` script requests 1200 frames at 640×360 on `wayland-0-gpu`, using `/opt/fex/FEX-apple-m1-munmap` without a preload shim and the isolated Mesa 26 overlay. `build4445-patched-cube.txt` identifies Virtio-GPU Venus (Apple M2 GPU), exit 0 and 59.09 seconds total, including startup. `cube4445-patched-visible-a.png` and `cube4445-patched-visible-b.png` show distinct orientations in the same cube window. This verifies bounded GPU presentation and motion. Dividing frames by the startup-inclusive duration would not establish steady-state FPS.

The patched FEX and Mesa overlay are separately installed in the Linux guest data; they are not embedded in this IPA. Their hashes and pinned source revisions are recorded in `build-manifest.json` and `gpu-validation-provenance.json`. The FEX rebuild and its 18-case allocator regression are archived beside this folder in `../fex-munmap-repair/`. The recorded Hollow Knight run reaches Unity 6000.0.61f1 and Vulkan physical-device detection, but fails main-window creation because `libGL.so.1` is missing. It was manually stopped with 137; that is not a natural-crash result or gameplay validation. The full game evidence is curated separately.

The signed executable and dSYM share UUID `1E4E9B30-C8D1-3F7C-918B-59CFE8B7CCBB`. Independent deep/strict codesign verification passes with normal macOS trust access, and both approved memory entitlements are true. IPA and dSYM ZIP pass full CRC checks; embedded metadata, executable, root archive and DWARF match the originals. The embedded root archive is unchanged from build 4443. All five source snapshots match the build commit and the source rechecked after compilation. No separate pre-build dirty-state snapshot is claimed.

`SHA256SUMS` covers local artifacts; `REPOSITORY-SHA256SUMS` covers the lightweight repository copy. IPA and symbols remain outside Git. Packaging is ready for private publication by the main task, with the above GPU/game boundaries retained. This packaging task performed no upload or release, and historical build 4443 artifacts remain intact.
